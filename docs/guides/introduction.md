# Introduction

The Global Heat Flow Database web portal is built on top of the FairDM framework, which provides a foundation for building data-driven web applications with a focus on FAIR principles. Many of the features found in the portal are provided, and documented by, FairDM itself. Rather than duplicating that documentation here, please refer to the following useful resources:

- [Creating anf managing a FairDM project](https://fairdm.readthedocs.io/en/latest/user-guides/projects)
- [Creating and managing a FairDM dataset](https://fairdm.readthedocs.io/en/latest/user-guides/datasets)
- [Adding and Managing samples](https://fairdm.readthedocs.io/en/latest/user-guides/samples)
- [Adding and Managing measurements](https://fairdm.readthedocs.io/en/latest/user-guides/measurements)
