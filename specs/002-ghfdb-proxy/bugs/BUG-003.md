# Bug Report: Child Admin Changelist Crashes on Invalid `prefetch_related()` Path

**Type**: Implementation drift
**Severity**: High
**Feature**: 002-ghfdb-proxy
**Reported**: 2026-04-17
**Status**: Patched
**Patched**: 2026-04-17

## Description

The `GHFDBChild` admin changelist fails at runtime with:

`Cannot find 'publication_references' on HeatFlow object, 'publication_references' is an invalid parameter to prefetch_related().`

This was introduced during the previous BUG-002 child-admin refactor. The changelist queryset added a `prefetch_related("publication_references")` path that does not exist on `HeatFlow`, causing the admin list view to error instead of rendering.

## Root Cause Analysis

The BUG-002 implementation expanded child-admin queryset prefetches to support additional child columns, but included a relation name that is not present on `HeatFlow` (`publication_references`). This is an implementation-level mismatch between assumed and actual ORM relations.

Because the optimization path was not validated with a test that forces evaluation of all prefetch lookups in the final changelist queryset, the regression reached runtime.
